文件夹日历同步

供个人使用的 Windows 本地工具，读取指定分类中绿色数字文件夹的最小编号，并将当天结果记录到用户自己的 Google 日历。每天北京时间早上 8 点运行。

日历记录仅包含分类名称及编号，每个分类单独一行。此网站仅提供应用说明，不提供登录或授权功能。

隐私政策 · 使用说明

隐私政策

生效日期：2026 年 10 月 22 日

此工具在用户的 Windows 电脑上运行。它读取用户选定目录下的文件夹名称和图标设置，用于识别绿色文件夹、计算最小数字编号。它不读取或上传文件夹中的照片、视频或其他文件内容。

用户通过 Google OAuth 授权后，工具访问用户拥有的日历中的日程，以创建、查询和更新本工具的每日编号记录。发送给 Google 的业务数据仅为分类名称、数字编号及日程时间等必要的日程属性，不包含本地完整目录路径或文件内容。

Google 授权令牌使用 Windows DPAPI 加密保存在用户本机，只有同一 Windows 用户能解密。执行日志和最近同步状态也保存在本机。日程记录保存在用户的 Google 日历中，其可见范围遵循用户自己的日历共享设置。

此说明网站不收集 Google 登录凭据、访问令牌、文件夹数据或日历记录，不使用广告、分析脚本或追踪 Cookie。静态网站托管服务可能处理提供网页所必需的常规访问请求。

本工具不出售用户数据，不将用户数据用于广告或模型训练。对 Google 用户数据的使用和传输遵守 Google API Services User Data Policy，包括 Limited Use 要求。

用户可随时在 Google 账号权限设置中撤销授权，在 Windows 任务计划程序中停止定时任务，删除本地授权文件、日志及状态记录，并在 Google 日历中自行删除日程。撤销授权后，工具不能继续写入日历。更改隐私实践时应同步更新本页。

使用说明

工具仅供账号持有人个人使用。定时运行需要电脑开机、Windows 用户已登录、源目录可访问且网络可连接 Google。用户可锁屏或关闭 GPT。电脑关机时无法记录当时状态；恢复后可能记录当天的当前状态。

如 Google 撤销授权、网络中断、源目录不可访问或权限变更，同步可能失败，具体情况保存在本机执行日志。请按需要检查日历记录及任务运行状态。

本页不包含个人文件夹编号、本地路径、邮箱地址或授权凭据。
